# ☕ AeroPress: Kirkland Tostado Medio (Invertido)

## ☕ Ficha técnica
- **Método**: AeroPress (Método Invertido)
- **Ratio**: 1:15
- **Café**: **15g** (Kirkland Tostado Medio)
- **Agua**: **225ml**
- **Molienda**: Media-Fina / **Nivel 35** en DF54
- **Temperatura**: **195°F (90°C)**⚠️

## 🛠️ Equipamiento adicional
- [x] Filtro de papel (Enjuagado)
- [x] Báscula
- [x] Cronómetro
- [x] Agitador / Cuchara

## 📝 Procedimiento
1. **Configuración**: Colocar la AeroPress en posición invertida (el émbolo hacia abajo, la parte abierta hacia arriba). Agregar los 15g de café molido.
2. **Vertido**: Agregar los 225ml de agua de manera rápida y constante para asegurar que todo el café se sature de inmediato.
3. **Agitación**: Agitar vigorosamente con el agitador durante 10 segundos. Esto es clave con el Kirkland para romper grumos de un tueste más aceitoso y asegurar una extracción uniforme.
4. **Reposo**: Colocar la tapa con el filtro previamente enjuagado y esperar hasta que el cronómetro marque **1:30 min**.
5. **Inversión**: Con un movimiento fluido y seguro, girar la AeroPress sobre la taza o recipiente.
6. **Presión**: Presionar de forma suave y constante. El proceso de bajada debe durar unos **30 segundos**. Detenerse inmediatamente al escuchar el siseo del aire ("The Hiss").

## 💡 Notas y consejos
- *Al ser un café comercial, el **Nivel 35** es el punto de equilibrio; si se baja a 30 (más fino), el amargor del tueste medio opacará las notas de chocolate.*
- *Se utiliza **195°F** porque a 205°F el Kirkland tiende a soltar sabores astringentes y amargos muy rápido bajo el método de inmersión.*
- *Si la taza se percibe muy "pesada" o intensa, intentar un ratio de 1:16 (15g de café por 240ml de agua) manteniendo el mismo nivel de molienda.*
- *Tiempo total de contacto estimado: 2:00 - 2:15 min.*
